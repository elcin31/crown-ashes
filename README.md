# Crown & Ashes 0.4.0 — Living Kingdoms

Продолжение существующей Godot-игры в единственном репозитории `elcin31/crown-ashes`.
12 архитектурных стилей, 140 новых зданий, 32 анимированных набора, жители и важные
путешественники на маршрутах; журнал 24 основных / 36 побочных / 12 динамических заданий.
Все события прежней кампании Ниязовых сохранены.

Задания открываются кнопкой **Задания** в верхней панели. Там же доступны история,
путешественники и каталоги. Время останавливается при открытии окна; Back возвращает
к карте. Для движения жителей запустите время. Развитие и строительство используют
прежние игровые команды.

Доставка: `exports/CrownAndAshes-v0.4.0-android.zip` содержит только настоящий APK.
Это ARM64 debug-сборка с отдельным пакетом `org.crownandashes.livingkingdoms`, чтобы
не удалять 0.3.1 и его данные при отсутствии прежнего signing key. Обновление поверх
старого пакета требует исходного ключа. JSON-сохранения формата 1 мигрируют без
переименования персонажей и изменения старых систем; автоматического переноса между
разными Android-пакетами нет.

Подробности реализации и ограничения: [docs/LIVING_KINGDOMS_0.4.0.md](docs/LIVING_KINGDOMS_0.4.0.md).
Проверки: [docs/LIVING_CHECK_0.4.0.json](docs/LIVING_CHECK_0.4.0.json),
[docs/ART_CHECK_0.4.0.json](docs/ART_CHECK_0.4.0.json),
[docs/BUILD_INFO_0.4.0.json](docs/BUILD_INFO_0.4.0.json).
Художественный стандарт: [ART_DIRECTION.md](ART_DIRECTION.md).

Сборка использует Godot 4.6.3 и прежний Android preset. После настройки Android SDK,
JDK и debug keystore в Godot: `python3 tools/build_android.py --coexist --template /path/to/android_debug.apk`,
затем `python3 tools/package_android.py`. Без `--coexist` сохраняется исходный package ID;
для обновления установленной игры обязательно нужен её исходный ключ подписи.
Локальные SDK, шаблоны, ключи и журналы находятся в игнорируемой `.build/`.

## Наследие Ниязовых

«Новая игра» предлагает сюжетную кампанию за **Александра I Ниязова**, 34 года,
или свободную игру за любое доступное владение. Обе используют одну симуляцию.
Королевство Аурелиан, столица Хаймир, 1183 год. Елизавета Вейр — супруга короля;
Михаил — младший брат, Даниил — сын и наследник, София — сестра, Виктор — боковая
ветвь. Общие предки, браки, рождения, смерть и смена правителя — игровые данные.

Четыре акта: **Расколотая корона → Кровь и знамёна → Цена власти → Наследие**.
**24 основных главы, 9 альтернатив**, 8 возможных итогов. Окна появляются по
игровой дате и обстоятельствам; решения можно отложить, закрыв окно и вернувшись
к карте. «История» показывает задачи, угрозы, претендентов и хронологию решений.

Уступки повышают верность, централизация укрепляет власть, содержание двора стоит
ресурсов. Развитие, назначения, расследования и браки выполняют обычные команды.
Мятеж не обязателен: длительный кризис и низкая верность землевладельца создают
настоящую войну через прежнюю систему восстаний. После смерти Александра история
продолжается за допустимого преемника; другая семья может выиграть выборы.
Финал не прекращает свободную стратегию, пока сохраняется владение и преемственность.

60 провинций, 12 независимых государств и малое вассальное владение. Сохранены
экономика, торговля, строительство, семь типов войск, походы, бои, осады, мирные
договоры, дипломатия, ИИ и обычные события. В свободной игре цель — 35 провинций,
императорский титул и стабильность ≥50 без оккупации 180 дней.

Старые кампании **не переименовываются** и не получают принудительный сюжет.
При загрузке восстанавливаются целочисленные ID в массивах родства, притязаний,
маршрутов и прохода: JSON иначе превращает их в float и нарушает Array.has.

## Управление

Android: один палец — движение, два — масштаб, касание — выбор провинции/армии.
Поход: армия → «Указать цель» → провинция. Окна прокручиваются. Back закрывает
панель, отменяет выбор или открывает паузу. Кампания начинается на паузе;
1× — около одного игрового дня в секунду. Три ручных слота и автосохранение.
Desktop: перетаскивание, колесо, Home — столица, пробел — пауза, Esc — назад, F5 — сохранить.

## Сборка и структура

Установите Godot 4.6.3 и его export templates, JDK 17+ (использован 21), Android SDK.
Укажите SDK/JDK и прежний debug keystore в Editor Settings → Export → Android.
Ключи в Git не хранятся. Откройте `project.godot` для настольного запуска.

```bash
godot --headless --path . --editor --import --quit
./tools/build_android.sh
```

Результат — `exports/CrownAndAshes-v0.3.1-android.apk`, ZIP только с этим APK и SHA256SUMS.
Workflow `Android downloadable package` публикует проверенный готовый APK как artifact.

- `scripts/core`, `economy`, `military`, `politics`, `ai` — общие игровые правила.
- `scripts/characters/house_niyazov.gd` — канон только для новых кампаний.
- `scripts/events/narrative_system.gd`, `data/narrative.json` — сюжет поверх EventSystem.
- `scripts/world`, `scripts/ui_controller.gd` — карта, жесты и интерфейс.
- `assets/`, `assets_manifest.json` — текстуры, размеры, назначение, анимации.
- `tools/art_sources/` — исходные авторские атласы; Python/Pillow: `generate_assets.py` (включает `settlement_art.py`),
  затем `bake_world.py`. `generate_story.py` воспроизводит сюжетные определения.
