# Ограниченные проверки 0.3.0

Godot 4.6.3, Xvfb/Mesa llvmpipe. Android-устройства/эмулятора нет.

Один общий короткий запуск объединил проверку меню, сюжета и ключевых экранов:
InputEventScreenTouch через Input.parse_input_event → новая игра → сюжет →
Александр → коронация → решение → карта → династия → Back → история → налоги →
сохранение → меню → продолжение → 13 игровых дней → следующая глава.
Проверены также свободная игра, 260 Godot-текстур, наследование Даниилом,
законная смена династии при выборах, имя новорождённого, верная/умершая ветка Михаила
и совместимость контрольного сохранения 0.1. Многолетней симуляции не было.

В основном запуске 350 из 351 проверок прошли. Один сбой выявил различие типов ID
после JSON-загрузки: Array.has отличает int от float. Родословная в файле была
правильной, но проверка принадлежности не работала. Это затрагивало также притязания
и военный проход. SaveSystem теперь восстанавливает только известные массивы ID,
не переименовывает персонажей и сохраняет неизвестные поля/формат 1.

Одна целевая визуальная проверка исправления подтвердила читаемое сюжетное окно,
касание выбора и общих предков боковой ветви. Исправлена узкая HBox-строка,
переносившая заголовок по буквам. После окончательного исправления ID повторена
только загрузка/членство: **124 проверки, 0 ошибок**. Общая последовательность не
повторялась. Исходные результаты и целевые отчёты сохранены без подмены:
`SMOKE_0.3.0.json`, `TARGETED_0.3.0.json`, `SAVE_ID_FIX_0.3.0.json`.

Один пакетный контентный контроль: 260 уникальных PNG, 245 изменённых старых,
12 новых сцен и 2 гербовых ресурса; 36 листов/1440 кадров с различными walk/action.
33 определения сюжета покрывают 24 главы четырёх актов, включая 9 альтернатив.
Проверены размеры, прозрачность, отсутствие пустых/повторных изображений и ссылки
сюжетных иллюстраций. `ASSET_CHECK_0.3.0.json`.

Художественный контроль: меню, столица/карта, событие, династия и история в
`screenshots/0.3/`; до/после — `map_before_0.3.png`, `map_after_0.3.png`.
Средняя HSV-насыщенность миниатюры мира выросла с 0.4171 до 0.5563; это проверка
цветовых данных, а не самостоятельная оценка художественного качества.
Полная библиотека в desktop-прогоне заняла 83 531 109 байт texture memory;
это не RSS, Android-память или измерение FPS.

Android: один standalone debug export; проверяются ZIP/CRC, manifest/DEX/ARM64,
v2/v3-подпись, прежний сертификат/package ID и отсутствие разрешений. Итоговый ZIP
содержит только `CrownAndAshes-v0.3.0-android.apk`. Метаданные — `BUILD_INFO_0.3.0.json`.
Workflow поставки проверяет и публикует готовый APK, не запускает новую сборку.
