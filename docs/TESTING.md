# Ограниченные проверки 0.2.0

Godot 4.6.3, Linux/Mesa llvmpipe/Xvfb. Android-устройство, KVM и Android-эмулятор
в среде отсутствуют: реальная установка/запуск APK и FPS на Redmi Note 12 не проверены.

## A. Направленная диагностика Android-меню

Причина: в 0.1 `input_devices/pointing/emulate_mouse_from_touch=false`.
Стандартные Godot Controls не получали нужный им mouse-input из касаний.
Прежняя визуальная проверка вызывала методы меню напрямую и пропустила дефект.

Исправление: штатная эмуляция включена, карта игнорирует синтетическую mouse-копию
и принимает родные touch-жесты. Касание UI не начинает жест на карте; декоративные
изображения игнорируют ввод. При замене модального окна старый Control скрывается
и освобождается в конце кадра, без удаления из дерева посреди input dispatch.

В одном направленном сценарии воспроизведено старое поведение с выключенной эмуляцией,
затем включено исправление. **37 проверок, 0 ошибок**: настройки/загрузка, новая игра,
выбор государства, запуск, провинция, действие, сохранение/загрузка, меню и продолжение.
Во время подготовки исправлены два условия самого сценария: он должен искать кнопку
в верхнем модальном окне и пропускать отключённые кнопки пустых слотов.

## C. Короткая игровая последовательность

`tests/input_smoke.gd` отправляет **InputEventScreenTouch/ScreenDrag через Input.parse_input_event**,
а не вызывает `Button.pressed` и методы переходов напрямую. Последовательность:
главное меню → новая кампания → Вейрмарк/Хаймир → запуск → провинция → экономика →
изменение налогов → династия → Back → pinch → армия → отмена выбора → ручное сохранение →
загрузка → главное меню → продолжение. Проверен контрольный файл сохранения 0.1 (формат 1).

Итого **287 проверок, 0 ошибок**, включая 246 проверок Godot-текстур и короткий UI-сценарий.
Скриншоты — `screenshots/0.2/`, машинный итог — `SMOKE_0.2.0.json`.
Уведомление Android Back проверено в коде обработчика, не на Android-устройстве.

При загруженной полной библиотеке: около **71.4 MiB** GPU texture memory и **39.8 MiB**
static memory в настольной среде. Это не измерение общего RSS, Android-памяти или FPS.
Иллюстрации и портреты в обычной игре загружаются при открытии окон; тест загрузил всё.
