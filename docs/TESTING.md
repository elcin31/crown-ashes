# Ограниченные проверки 0.3.1

Godot 4.6.3, Linux/Xvfb/Mesa llvmpipe. Реального Android-устройства/эмулятора нет.

Одна короткая игровая последовательность: касания меню → новая сюжетная кампания →
коронация/решение → карта/провинция → шесть панелей → налоги → Back → pinch →
время/пауза → ручное сохранение → главное меню → продолжение. Она прошла; экономика,
войны и династии заново длительно не симулировались.

Первый общий сценарий содержал 236 проверок, из которых 10 выявили проблемы layout
и сценария изменения размера. Исправлены переносы кнопок скорости/toolbar.
Изменять размер нужно через Godot Window.size: прямой вызов DisplayServer в этой
среде не обновлял размер Viewport. После этого проверены реальные клиентские окна:

| Экран | Логический холст |
|---|---|
| 1920×1080 | 1280×720 |
| 2340×1080 | 1560×720 |
| 2400×1080 | 1600×720 |
| 2460×1080 | 1639×720 (округление движка) |

Целевой повтор подтвердил пропорции, выбор провинции касанием, границы панелей,
высоту header 90/toolbar 48 и эмуляцию отступов выреза. 68 из 72 проверок прошли;
четыре остальных ошибочно требовали высоту всех верхних кнопок ≤52, хотя большая
кнопка паузы занимает 74 и полностью входит в header. Исправлено условие теста;
повторена только область нажатия: 14 проверок, 0 ошибок. Полный игровой сценарий
повторно не прогонялся. Перед сценарием импорт
также обнаружил и позволил исправить опечатку в инициализации UI.

Машинные результаты сохранены без подмены: `SMOKE_0.3.1.json`,
`LAYOUT_RECHECK_0.3.1.json`, `HIT_AREAS_0.3.1.json`. Полный обновлённый сценарий:
`tests/mobile_smoke.gd` (`--mobile-smoke`); целевые флаги — `--layout-recheck`, `--hit-check`.
ScreenTouch/ScreenDrag подаются в физических координатах с учётом CanvasItems stretch.

Один художественный проход: 12 оригинальных замен, три композиции; все 263 PNG
декодированы Pillow, новые текстуры загружены Godot. Контроль —
`building_comparison_0.3.1.png`, `screenshots/0.3.1/`, `ART_CHECK_0.3.1.json`.

Android: один локальный standalone debug export. Проверяются подпись v2/v3,
совпадение сертификата с 0.3.0, package/version, ZIP/CRC и ровно один APK в ZIP.
Факты — `BUILD_INFO_0.3.1.json`. Установку, реальные жесты и FPS на телефоне
подтвердить нельзя: подходящего устройства нет.
