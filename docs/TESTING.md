# Ограниченная проверка 0.1.0

Среда: Godot 4.6.3 stable, Linux, Mesa llvmpipe / Xvfb, Python 3 + Pillow.
Длительное профилирование и многолетняя симуляция не проводились.

1. **Основная проверка**: импорт проекта и запуск с `--visual-check`. Новая игра,
   главное меню, хозяйство, дипломатия, династия, стройка, набор, интриги, законы,
   брак и настройки открылись без ошибок скриптов. Все 136 текстур прочитаны Godot.
   Проверены касание/перетаскивание, изменение масштаба, сохранение/загрузка.
   Скриншоты находятся в `docs/screenshots/`.
   Проверка контента подтвердила 136 уникальных PNG, 448 кадров, различные кадры
   ходьбы и действия, прозрачность, 60 связных провинций, общие границы и 33 события.
   Обнаружены совпадение двух домов и чрезмерное сужение текстовых колонок;
   исправлены генератор и контейнеры, повторена именно эта неудачная проверка.

2. **Целевой сценарий механик**: `godot --headless --path . --script tests/mechanics.gd`.
   **33 проверки, 0 неудач**. Короткая кампания: пауза, расход ресурсов, очередь
   строительства, окончание работ, набор, переход, торговый спред, дипломатия и cooldown.
   Отдельная небольшая боевая ситуация: основание войны, потери, поход, осада,
   оккупация, ограниченная передача земли при мире, перемирие и наследование.
   Сохранены дата/место армии/состояние RNG, испытано восстановление резервной копии
   после намеренного повреждения основной записи. Сообщение JSON parser об
   `interrupted` в этом сценарии ожидаемо и относится только к тестовому повреждению.
   Полные многолетние кампании и исчерпывающая проверка всех событий не проводились.

3. **Android APK**: стандартный экспорт Godot из официального шаблона без Gradle.
   Исправлена конфигурация debug credentials, убраны неподдерживаемые без Gradle
   overrides Min/Target SDK, включён требуемый Android import ETC2/ASTC.
   Во время подготовки потребовались дополнительные короткие попытки экспорта для
   устранения этих ошибок конфигурации; повторных игровых аудитов не было.
   Системная кнопка Back обрабатывается игрой; автоматический выход SceneTree отключён.
   APK проверен ZIP CRC, наличием manifest/DEX/ARM64 Godot-библиотеки и игрового контента,
   `apksigner verify` (v2/v3), package ID и отсутствием запрошенных разрешений.
   ZIP содержит ровно `CrownAndAshes-v0.1.0-android.apk`.
   Debug, ARM64, min API 24 / target API 36 — значения официального шаблона 4.6.3.
   Подключённых устройств и эмуляторов нет; установка и запуск Android не выполнялись.
   60 FPS на Redmi Note 12 не измерялись.

Повтор механик без загрязнения обычных сохранений:

```bash
XDG_DATA_HOME=/tmp/crown-ashes-test godot --headless --path . --script tests/mechanics.gd
```

Экспорт Linux также выполнен из того же проекта. Сценарий запуска проверял исходный
Godot-проект; отдельный длительный прогон экспортированного бинарника не проводился.
